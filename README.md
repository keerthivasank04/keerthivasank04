## Featured Projects

### [Scholarship Project Framework](https://github.com/keerthivasank04/scholarship-project-framework)
A containerized scholarship management platform covering application intake, rule-based scoring, field verification and administrative decisions, with role-based portals for students, verifiers and administrators.

- Configurable rule engine with per-program overrides and an immutable status audit log
